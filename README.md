# Pattern-Recognition
This repository contains the solutions of the project for the course 'Pattern Recognition and Machine Learning" (Αναγνώριση Προτύπων και Μηχανική Μάθηση) of ECE @ Aristotle University of Thessaloniki that is being taught by Assistant Professor Petrantonakis.
We developed at A-C numerical methods and at D a classifier for data given for it. The nature of the data supported for this project was unknown, since they were unlabeled.
